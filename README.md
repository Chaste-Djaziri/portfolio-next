# Portfolio Next

Personal portfolio built with Next.js App Router, React, TypeScript and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Checks

```bash
npm run lint
npm run typecheck
npm run build
```

Edit `src/app/page.tsx` for portfolio content and `src/app/globals.css` for global styles.
